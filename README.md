# BMI-Calculator
A lightweight console-based application built in Java designed to calculate a user's Body Mass Index (BMI) and provide an immediate health category assessment based on standard medical guidelines.

Features
-Dynamic Calculation: Computes BMI accurately using user-entered weight (in kilograms) and height (in meters). 
-Health Categorization: Automatically evaluates the calculated BMI and categorizes the result into Underweight, Normal weight, Overweight, or Obese.   
-Input Validation: Includes basic checks to ensure user inputs (such as height) are valid to prevent runtime calculation errors.

Key Concepts & LogicMathematical Logic:
-Implements standard formula-based calculations ($\text{weight} / \text{height}^2$).
-Conditional Statements: Uses if-else control flow to determine the correct health category.   
-Input Handling: Utilizes java.util.Scanner to capture and process user console inputs interactively.
